# UF-01: Landing Page & Information

**Product:** EXIT — Early Investment Take-over  
**Feature:** Landing Page  
**Actor:** Calon Pengguna  
**Related User Stories:** US-01, US-02, US-03, US-04  
**Access:** Public (tanpa login)

## 1. Deskripsi

User Flow ini menjelaskan proses calon pengguna dalam mengakses Landing Page EXIT untuk memperoleh informasi dasar mengenai platform, memahami mekanisme take-over posisi investasi, mengetahui fitur utama, serta memperoleh jawaban atas pertanyaan umum.

## 2. Rincian User Stories

### US-01: Informasi Dasar EXIT

**User Story:**

Sebagai calon pengguna, saya ingin mengetahui informasi dasar EXIT agar memahami tujuan dan manfaat platform.

**Acceptance Criteria:**
- Informasi pengenalan EXIT tersedia dan mudah dipahami.

### US-02: Informasi Cara Kerja EXIT

**User Story:**

Sebagai calon pengguna, saya ingin mengetahui cara kerja EXIT agar memahami mekanisme take-over.

**Acceptance Criteria:**
- Alur cara kerja EXIT ditampilkan secara jelas.

### US-03: Informasi Fitur Utama

**User Story:**

Sebagai calon pengguna, saya ingin mengetahui fitur utama EXIT agar memahami layanan yang tersedia.

**Acceptance Criteria:**
- Informasi fitur utama tersedia pada website.

### US-04: Frequently Asked Questions (FAQ)

**User Story:**

Sebagai calon pengguna, saya ingin memperoleh jawaban atas pertanyaan umum agar memahami penggunaan EXIT.

**Acceptance Criteria:**
- FAQ memuat pertanyaan dan jawaban yang relevan.

## 4. Output

Landing Page EXIT yang menyediakan:
- Informasi dasar mengenai tujuan dan manfaat EXIT.
- Penjelasan mekanisme take-over posisi investasi.
- Informasi fitur utama platform.
- FAQ untuk membantu calon pengguna memahami EXIT.

## 5. Catatan

- Landing Page ditujukan untuk calon pengguna yang belum login.
- Proses registrasi dan login dibahas secara terpisah dalam UF-02: User Authentication.
- Informasi dan mekanisme yang ditampilkan harus sesuai dengan ruang lingkup prototype EXIT.
- Prototype menggunakan data simulasi dan tidak merepresentasikan transaksi investasi riil.
